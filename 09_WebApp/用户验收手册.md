# GPX Terrain Lab 本地 Web 用户验收手册

## 启动

1. 双击 `09_WebApp/start_local.command`；
2. 浏览器打开 `http://127.0.0.1:4173/`；
3. 页面右上角应显示“本地模式 · 数据不离开电脑”。

不要直接双击 `local/index.html`。`file:///` 页面无法调用本机 Blender 服务；新版页面检测到这种打开方式会自动跳转到本地服务地址。

## 用户验收流程

### 01 输入

选择 GPX 后，文件名、轨迹点数与里程应出现；红色轨迹应变为该 GPX 的平面形状；“下一步：工程参数”应由灰色变为可点击。

### 02 工程

核对 100 mm、Resolution 8、高程 1.80、轨迹宽度 1.60 mm。任意改动一个值，底栏应提示偏离真机基线；点击“恢复真机参数”应复原；水网默认开启。

### 03 创意

修改标题后，预览卡标题应立即同步；日期可修改；“上一步 / 下一步”均应正常。

### 04 Blender 仿真与输出

1. 检查 5 个 3MF + 1 个 Blender 输出清单；
2. 点击“启动 Blender 仿真”；
3. 等待状态从“处理中”变为“仿真完成”；
4. 页面应以 Blender 渲染替换快速草模，并出现“装配透视 / 顶视关系 / 侧视高度”三个机位；
5. 图中应看见真实地形起伏、红色轨迹、蓝色水系和灰色参考底座；
6. 点击“生成最终 5+1”，状态应变为“QA PASS”；
7. 页面应出现 5 个 3MF、1 个 Blender 的独立下载卡，每张显示大小、短 SHA 和 PASS；
8. 点击“下载完整 5+1 套装”或底部“下载完整套装”，应得到含六个文件及 `SHA256SUMS.json` 的 ZIP；
9. 刷新页面后，上一次完整成果应恢复到交付槽位，可直接再次下载。

通过标准：不得出现空白图、极小模型、固定假轨迹，也不能把快速草模称作最终打印效果。
