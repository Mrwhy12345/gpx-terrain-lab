## 柏林 V7R13 提炼的执行方法
| 环节 | 默认执行 | 验证方式 |
|---|---|---|
| 水路与安装槽 | 保留原生轮廓；完成水系/桥梁/道路后最后统一扣最终轨迹和地标槽 | 对比原生足迹，区分真实独立水体、安装槽断口和错误断路；查实体干涉与顶装路径 |
| 普通建筑承托 | 窄残片单独审查，隐藏根部形成有效咬合，顶部不随意改变 | 沙盘关闭支撑复切；异常按材料→连通组件→二分定位；不以闭合代替承托 |
| Tripo 地标 | 基于源模型简化加固脆弱细节，保留识别特征，不另创造型 | 最薄特征、支撑接触和拆除可达性；必要时先打印地标 |
| 文字 | 字体转最终实体后，按边框切向及法向包络居中，保留两侧安全余量 | 不侵占承座、不超外边；最终刀路逐字可读 |
| 高度与底纹 | 底座/下沉/露出分别参数化；底图从锁定 PNG 提取 | 同尺度侧视确认；底面正常阅读及真实首层刀路 |
| 原生工程 | 连同几何保留材料与机型配置，缺失即停，不静默回退 | 引用槽和模板数组结构一致；最终工程打开、保存、重开、复切 |
| 打印放行 | 每次打印新建唯一 Run，绑定 3MF 哈希、机型/喷嘴、材料槽位、工艺与 GUI 截图 | `GUI_PASS` 只对该文件和配置有效；模板见 `07_Knowledge/Templates/马拉松_打印放行与PrintRun记录模板.md` |
| 复打 | 开印前只写本次变更、冻结不变、验证假设；失败 Run 也保留 | 尽量复用首印拍摄角度逐项对比；新哈希或关键设置变化必须重新放行 |
| 交付 | 主 3MF 与同版打开即见 Blend 同时提供，缺项明确列出 | 从最终制造文件回读，同版图片/QA/哈希；不得以局部 PASS 宣称全套完成 |

## 复用边界
- 西安 R11 真机经验速查：旧底座先清除跨城市暗纹；独立轨迹核对平底接触面积与真实首层路径；地标先判完整台基或插脚，再做同源槽并查支撑实际高度；三边字形按原生双通道生成且逐字逐层复切；底图按锁定 PNG 扣图、预处理、镜像、嵌入。具体数值只查标准契约 §12 和西安 Job，不从案例直接抄作通用默认。
- 柏林实物满意不意味着其每项参数均为通用最优。8/0.8/3 mm 高度、建筑下沉量、删除组件及坐标均只属柏林。
- 允许复用方法、工具和经过验证的配置结构；新城必须重新核验事实、配色和机型映射。
- V7R13 实物照片与用户接受见柏林 Job 的 review/V7R13_真机验收_20260918；不是全部诊断配置已通过。
- 本页是执行规范，不表示所有检查已实现为通用脚本。二分定位目前仍为项目方法，自动化待后续复用时抽取，禁止无关重写。
