# 底座原图元素 PNG 嵌色通用流程

版本：1.1
日期：2026-09-09
适用：马拉松、越野跑、徒步沙盘和冰箱贴的底座底面图案

## 1. 产品原则

底图的任务是唤起跑者对赛事和城市的共鸣，不是把海报或奖牌全部缩印到底座。

固定链路：

> 可追溯原图 → 抠出共鸣元素 → 候选图 → 用户看图选定 → PNG 锁稿 → 制造轮廓 → 底座浅槽+独立嵌色件 → 同源 QA

PNG 是唯一审美母版，不是允许程序再次发挥的草图。FDM 刀路最终仍需要闭合实体，
但实体只能由锁稿 PNG 的 alpha／亮度轮廓机械提取；禁止在 PNG 确认后再用圆、柱、
线段、曲线或其他程序化几何重新绘制、替代或“优化”原图。这里的实体化是忠实嵌入，
不是二次设计。

## 2. 五阶段流程

### A｜原图与边界

1. 优先级：用户提供的实物照 > 赛事官方图 > 政府/场馆权威图 > 其他网络参考。
2. 保存原始文件、来源 URL、获取日期、SHA-256 和使用边界。
3. 看不清的字、微纹和标识不猜；没有原图时不凭文字臆造“官方图案”。
4. 网络图像只提取允许使用的主题元素或做原创转译，不默认整图复制发布。

### B｜共鸣元素筛选

每张原图最多提取 3–5 个元素，按下列条件筛选：

- 跑者能说出它与赛事/城市的关系；
- 缩到 25–40 mm 仍能辨认；
- 单色轮廓成立，不依赖渐变和微小文字；
- 不与底座边框、磁铁孔、边缘文字或装配结构冲突。

输出《元素选择卡》：名称、来源、共鸣理由、小尺寸风险、使用边界。

### C｜PNG 候选与人工选定

1. 去背景、去文字、去摄影阴影，只保留主元素。
2. 输出黑色图形+透明背景的正方形 PNG；若工具无法保留 alpha，则使用近白背景和明确阈值。
3. 线条必须粗、连续、主次明确；避免孤立噪点和头发丝级细线。
4. 先展示 PNG，用户明确回复“选 X / 就这么定”后才锁稿。
5. 锁稿后保存哈希；尺寸补偿不得改变主轮廓、表情、姿态和负形。
6. 用户若选择候选 A/B/C，必须将该张候选单独保存为 `production_master.png`；
   不得根据文字描述另画一个“近似 A/B/C”。
7. 若 PNG 已有可信透明通道，锁稿与制造均以 Alpha 为唯一轮廓事实，必须使用 `alpha_only`；不得再次以 RGB 亮度阈值解释。若棋盘格已烘入 RGB，只允许确定性恢复 Alpha，并保存恢复前后图、哈希和像素差异报告。

### D｜实体化与嵌入

1. 以 alpha 或亮度阈值提取像素，先降采样到可控分辨率，再转闭合多边形。
2. 小范围开闭运算只用于抗锯齿和去噪；导致外观改变时退回 C 门。
   禁止以“更容易建模”为由，把 PNG 改画成规则几何图标。
3. 按实际喷嘴和层高设定最小线宽、最小间隙、浅槽深度和 XY 间隙。
4. 底座差集开槽，同一轮廓拉伸成独立嵌色件；两者禁止重叠体积。
5. 结果是多色底座的“材料子件”，不新增物理安装件数量。

推荐默认值（0.4 mm 喷嘴）：

- 图案最大跨度：30–36 mm；
- 可见线宽：不小于 0.70 mm；
- 嵌色深度：0.45–0.60 mm；
- 刀具 XY 补偿：0.04–0.08 mm；
- 中心默认为底座有效安全区中心，不凭图像外框目测。

### E｜证据与发布门禁

必须同时检查：

- PNG 哈希与确认记录；
- 生产轮廓和真实底座底视图；
- 底座水密正体、非流形边、最薄特征；
- 嵌件与底座重叠体积为 0；
- 3MF 中的底座和嵌色件来源哈希与已检查 STL 一致；
- Bambu Studio 底层刀路能看到完整图案；
- 锁稿与生产轮廓方向一致，未镜像或上下颠倒，连通组件数量符合设计；
- 最终主 3MF 回读仍包含同一材料子件，不能只引用实体化阶段的 STL PASS；
- 真机打印前状态最高只能是 `DIGITAL_PASS_PRINT_TEST_REQUIRED`。

## 4. 梧州醒狮成功样本

- 事实源：用户提供的 2026 梧州半马实物奖牌和官方开启图。
- 共鸣元素：奖牌中央醒狮，而不是全部文字和花边。
- 失败教训：未看到原图前的程序化“狮子/花瓣”重画与实物不符，已废弃。
- 审美母版：`08_Jobs/WEB_20260903_2026梧州半程马拉松_V1/input/medal_reference/derived/06_奖牌狮子浮雕源图_V1.png`。
- 用户确认：2026-09-03，“挺好看的，就这么定”；后续底视实体图再确认 `OK`。
- 制造参数：34.0 mm 最大跨度，0.46 mm 嵌色深度，图案居中。
- 结果：底座水密，嵌件与底座重叠 `0.0 mm³`，几何 QA `PASS`。
