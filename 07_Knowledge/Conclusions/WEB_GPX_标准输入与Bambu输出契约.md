# GPX Terrain Lab｜两步路 GPX 输入与 Bambu Studio 输出契约

状态：当前项目标准  
确认日期：2026-08-13

## 边界

- 标准输入：“两步路”导出的 GPX 轨迹文件。
- 标准切片与打印软件：拓竹 Bambu Studio。
- 标准产物：5 个 Bambu Studio 可用 3MF + 1 个 Blender 项目。
- “通用”是指不同路线的两步路 GPX 共用同一 Web 入口和生产链，不表示覆盖所有 GPX 方言或其他切片器。

## 2026-08-13 五样本回归

用户计划新下载 5 个两步路 GPX。每个样本必须独立新建 `WEB_*` 任务，禁止跨任务复用成品几何，并记录：

1. 文件名、SHA-256、轨迹点数与里程；
2. TrailPrint3D 地形和水系生成结果；
3. 轨迹连通体 `=1`；
4. 水系安装件尽量 `1–2`、且不超过 `5`；
5. 水系槽使用 `0.25 mm/侧`，与最终水件同源；
6. 5 个 3MF 在 Bambu Studio 可见、配色正确、无负 Z、在打印盘内；
7. Blender 文件打开可见；
8. 真机抽样的打印与装配结果。

## 升格条件

- 5 个新 GPX 全部完成 Web 任务和 `5+1` 生成；
- 无星溪标题、Logo 或旧任务几何泄漏；
- 至少一个非星溪样本通过水系 `0.25 mm/侧` 真机装配；
- 四件同盘在 Bambu Studio 拆件后严格为 4 个顶层对象。
