# 三路线全面回归测试方法

## 固定样本

1. `2025-02-23 从化星溪线.gpx`
2. `广州大夫山环穿画马（石马山～三乌岗～石马山）20251222+20260110（合并）.gpx`
3. `新兴水源山—孖山(风车山)环线.gpx`

脚本按 GPX 的 SHA-256 匹配最新完整 Web 任务，不依赖中文文件名或聊天上下文。

## 执行

```bash
python3 07_Knowledge/tools/run_three_route_regression.py \
  "/path/to/星溪.gpx" \
  "/path/to/大夫山.gpx" \
  "/path/to/风车山.gpx"
```

默认输出到 `00_Project/回归测试/三路线全面回归_时间戳/`，包含 Markdown 总报告、JSON 原始报告、每条路线的发布 QA、四对象 QA、Blender 材质审计和日志。

## 场景化质检

总规则见 `07_Knowledge/Conclusions/GPX_Terrain_Lab_场景化质检体系.md`。报告按 Q0 输入溯源、Q1 交付完整、Q2 可打印、Q3 可组装、Q4 工程真实性、Q5 创意审美、Q6 使用便利性分别给状态。

`NOT_TESTED` 是正式状态：自动几何通过不能替代真机打印和装配。

## 分级规则

- **P0（阻断）**：阻止当前目标场景交付，脚本返回非零。
- **P1（重大风险）**：缺少真机证据，或安装、强度、复杂度风险明显。
- **P2（一般问题）**：工程表达、创意或便利性问题。
- **P3（优化建议）**：审美、减件、性能与体验优化。

状态分为 `PASS`、`PASS_WITH_WARNINGS`、`BLOCKED`。当前阶段不追求所有指标全绿，只有 `BLOCKED` 阻止发布。

## 检查范围

- GPX 轨段和点数；
- 输入 SHA-256 与 Web 任务一致；
- 5 个 3MF + 1 个 Blender；
- 3MF ZIP、Z、打印盘边界；
- 三色地形微小碎片；
- 轨迹单一连通体和打印板接触率；
- 水系组件目标最多 5 个；超出记为 `WARNING`，不再单独阻断；
- 四件同盘严格为沙盘、底座、轨迹、水系四个顶层对象；
- 轨迹耗材槽 5（红）、水系耗材槽 4（蓝）；
- Blender 可见轨迹为红、水系为蓝；
- 最终 Blender 同源三机位图片齐全。

## 边界

自动回归不能替代 Bambu Studio 人工打开、切片时间/耗材评估、实际打印强度与安装公差验收。人工证据应单独记录；已知风险以 `WARNING` 或 `ADVISORY` 保留，不伪装成全绿。
