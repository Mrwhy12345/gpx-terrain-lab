# GPX Terrain Lab

把 GPX 轨迹转换成经过空间核验、可在 Blender 中预览、可多色 3D 打印的纪念沙盘。

## 两条产品线

- **徒步轨迹模型**：保留地形高程、自然水系和路线与山体的关系，面向徒步、越野和户外纪念。
- **马拉松轨迹模型**：以城市道路、水体、建筑、赛事路线和标志建筑构成奖牌式城市沙盘，强调美观、触觉辨识、拆装和多色打印效率。

两条产品线共享 GPX 审计、TrailPrint3D 事实层、Blender 制造层、3MF 封装和 QA 框架，但不得混用最终外观与打印结构标准。

## 产品目标

输入一个 GPX，经过 TrailPrint3D、GIS/OSM 审计、地图人工核验和制造几何生成，输出职责独立且保持同一装配坐标的模型、工程和 QA 证据。

徒步轨迹模型的典型输出包括：

- 地形 3MF；
- 底座 3MF；
- 徒步轨迹 3MF；
- 河流水体 3MF；
- 可选同盘 3MF；
- Blender 设计预览与 QA 报告。

马拉松轨迹模型的典型输出包括：

- 奖牌式底座；
- 水体、地面、道路和建筑组成的城市整体；
- 带触觉起终点的红色连续轨迹；
- 独立标志建筑；
- 标准 3MF、Bambu 原生工程、装配 Blend、来源记录和 QA/哈希清单；
- 精细文字版本采用一个工程两个盘：0.4 mm 主体盘＋0.2 mm 连续文字上框盘。

公开仓库不包含真实 GPX、精确路线坐标、密钥、3MF/Blend/STL 成果或实验缓存。
高德地图仅用于在线人工视觉核验，不作为模型数据源。

## 开发路线

1. 实体打印验收；
2. 参数化 `job.json`；
3. 单命令、可重试流水线；
4. 第二条路线无需改代码生成；
5. 本地优先 Web 工作台；
6. 五条路线数字回归、三次实体打印后再评估托管服务。
