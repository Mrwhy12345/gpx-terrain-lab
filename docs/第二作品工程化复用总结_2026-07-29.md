# 第二作品工程化复用总结｜大夫山画马

## 结论

“大夫山画马”是 GPX Terrain Lab 的第二个完整作品，也是首个验证“更换 GPX 后复用现有工具链”的样本。项目已经从单件模型研发进入可重复生产阶段。

输入一个新的 GPX 后，流水线完成了地形、水体、轨迹、安装结构、底座、创意 Logo、3MF 打包和 Blender 预览，最终输出 5 个 3MF 与 1 个 Blender 文件。

## 已复用的工程能力

- GPX 标准化、隐私隔离和路线事实提取
- 地形生成与低到高绿、棕、灰三段换色
- OSM 水体查询、距离排序、候选筛选和安装槽
- 红色轨迹安装件、跨水让位、起点箭头和终点靶心
- 真平行六边形底座、安装公差、磁铁孔
- 中文标题、日期和距离排版
- SVG Logo 双色嵌件
- GIS 坐标归零、Z 轴、非流形和打印平台边界检查
- 独立四件、同盘 3MF 与 Blender 默认可见视角

## 效率变化

第一件“星溪竹林”主要用于探索数据、几何、装配和切片方法。第二件直接复用这些成果，用户观察到 Token 消耗约为第一件的 20%+，低于“第二条路线不超过 S02 30%”的阶段目标。

本次 Token 主要用于新线路事实核验和创意选择，而不是重新研究基础建模，说明脚本、参数和发布门禁已经开始产生复利。

## 工程与创意分层

工程主线：

`GPX → 地形 → 水系 → 轨迹 → 装配结构 → 3MF/Blender → 自动 QA`

创意交互：

`路线与地图语义 → 标题 4 选 1 → 围绕标题生成 Logo 4 选 1 → 底座预览确认`

本次客户选择标题“大夫山画马”和 B“一笔画马”Logo。Logo 从概念图进入制造几何时采用高保真轮廓追踪与曲线平滑，不再用粗多边形重新临摹。

## 新增发布门槛

- Blender 交付前隐藏 GIS 远坐标辅助对象并保存默认相机视图
- Logo 必须先通过客户概念选择，再做矢量化与打印检查
- 图片转 Logo 必须保留曲线、负空间和整体比例
- final 只保留 5 个 3MF 与 1 个 Blender
- 公开示例不得包含原始 GPX、精确坐标、地图截图或内部地理数据

## 当前成熟度

- 单件作品能力：完成
- 更换 GPX 复用：已验证
- 半自动生产流水线：基本形成
- 客户创意交互：流程确定
- 对外系统：仍需上传入口、任务队列、失败恢复与实物参数标定
