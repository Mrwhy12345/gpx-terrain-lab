# Blender 学习笔记

此目录记录 ChatGPT 教学 Blender / TrailPrint3D 的过程笔记。

## 记录规范

每次学习后，将关键内容整理为一份笔记，文件名格式：`YYYY-MM-DD_主题.md`

笔记结构：

```
# 学习日期：主题

## 学到了什么

## 关键操作/命令

## 遇到的问题

## 下一步
```

## 学习目标

不学雕刻、骨骼动画、角色建模。聚焦：

| 必学 | 为什么 |
|------|--------|
| Scene / Object / Mesh / Collection | 理解插件生成了什么 |
| Object Mode / Edit Mode | 排查 Operator 失败 |
| 变换与坐标系 | 保证地形、水体、轨迹对齐 |
| Modifier 和 Boolean | 理解凹槽、裁切、拼接 |
| 材质与多对象 | 理解多色输出 |
| bpy 和后台模式 | 构建 Web 后端 |
