# 星溪线 V007 示例

这是 GPX Terrain Lab 的首个完整数字封版示例，展示从徒步轨迹、GIS 水体核验到
Blender 可制造几何和多色 3MF 的最终交付结构。

## 文件

### 用于打印

1. `01_星溪线_沙盘地形_水体安装槽.3mf`
   - 绿色、棕色、灰色三段地形；
   - 包含河流水体安装槽。
2. `02_星溪线_底座_居中文字_SVG竹林Logo.3mf`
   - 灰色底座与棕色文字/Logo；
   - “星溪徒步”使用 Hiragino Sans GB 转网格；
   - 包含 SVG 竹林 Logo 和磁铁孔。
3. `03_星溪线_徒步轨迹_红色.3mf`
   - 红色独立轨迹安装件。
4. `04_星溪线_河流水体_蓝色安装件.3mf`
   - 蓝色独立水体安装件。
5. `05_星溪线_四件同盘_按层打印.3mf`
   - 沙盘、底座、轨迹、河流同盘排布；
   - 默认使用按层打印，不建议直接改成逐件顺序打印。

### 设计预览

- `星溪线_沙盘完整设计预览_V007_中文字体修复.blend`
  - 完整装配设计源文件；
  - 可检查地形、轨迹、水体、底座、文字与 Logo 的关系。

## 推荐环境

- Bambu Lab H2C；
- 0.4 mm 喷嘴；
- Bambu Studio 02.07.01.62；
- Blender 5.2 LTS。

打开 3MF 后必须按实际 AMS/喷头槽位重新确认颜色映射。正式打印前应查看逐层
预览，重点检查轨迹连续性、水体细碎段、中文笔画和孤岛。

## 已完成 QA

- 五个 3MF 的 ZIP 结构完整；
- 所有文件的世界坐标最低 Z 为 0；
- 任一颜色组件均未落到打印床以下；
- 底座 3MF 为流形结构；
- 中文标题已经转为实体网格；
- 同盘文件外包络约为 254.66 × 181.60 × 17.31 mm。

同盘文件仍报告 42 条非流形边，因此它是经过自动核验的打印候选，不替代最终的
切片逐层检查。
