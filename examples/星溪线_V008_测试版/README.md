# 星溪线 V008 测试版：一体水系跨轨

> 状态：数字几何与 3MF 基础检查通过，尚待实物打印和装配验收。  
> 基线：V007 为已进入打印验证的稳定基线；V008 是独立测试版本。

## 本版目标

- 将被轨迹安装槽分开的河流水体合并为一个蓝色安装件。
- 水系与轨迹重叠时保留凹口，红色轨迹从水系上方跨过。
- 保持沙盘绿/棕/灰、轨迹红、水体蓝、底座灰/棕的配色。
- 修复单独底座 3MF 装配坐标越界、单独水体 3MF 误配红色的问题。

## 数字检查

- 水系原始独立区域：13
- 隐藏连接筋：12 条
- 水体最终连通组件：1
- 水体与低层地形非流形边：0
- 隐藏连接筋与轨迹垂直净空：约 0.571 mm
- 安装槽单侧间隙：0.12 mm
- 五个 3MF 最低 Z：0
- 单独地形项目位置：打印盘中心
- 单独底座项目位置：打印盘中心
- 单独水体显示色：蓝色 `#2563B8`

## 打印前注意

1. 本版不是实物验收完成版。
2. 在 Bambu Studio 中逐层检查轨迹—水系交叉位置。
3. 确认蓝色隐藏连接筋从首层连续成形，没有孤岛。
4. 四件同盘文件必须保持“按层打印”。
5. 实物重点验证水体整件强度、安装松紧、轨迹跨越和地形槽底厚度。
