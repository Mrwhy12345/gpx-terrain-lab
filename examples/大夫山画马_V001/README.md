# 大夫山画马 V001

GPX Terrain Lab 的第二个完整数字作品，也是首个“更换 GPX、复用 V012 等效工具链”的公开样例。

## 交付内容

- `用于打印_3MF/`：5 个 Bambu Studio 可用 3MF
- `设计预览_Blender/`：1 个完整装配 Blender 文件

配色：

- 地形：绿、棕、灰
- 水体：蓝
- 轨迹：红
- 底座：灰、棕

设计：

- 标题：大夫山画马
- Logo：B“一笔画马”曲线版
- 起点：箭头
- 终点：靶心

## 数字检查

- 底座与同盘 3MF 已通过 350 × 320 mm 打印平台边界检查
- 已检查 GIS 坐标归零和 Z 轴
- 已报告地形、水体、轨迹、底座与 Logo 非流形边为 0
- Blender 文件保存了打开即可看见完整模型的默认相机视图

## 状态

数字模型通过，等待实物打印与装配验收。建议首次打印重点检查轨迹槽、水体槽、底座配合与底面 Logo 清晰度。

## 隐私

公开示例不包含原始 GPX、精确坐标、地图截图、OSM 原始响应或过程地理数据。
