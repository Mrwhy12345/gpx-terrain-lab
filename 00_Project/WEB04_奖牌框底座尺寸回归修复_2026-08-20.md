# WEB04｜奖牌框底座尺寸回归修复

日期：2026-08-20
状态：V3 平行等宽环修复完成；修正版 5+1 数字 QA PASS；待 Bambu Studio / 实物装配复核

## 问题

Web 通用流水线误调用“按地形外扩边框”的底座生成器，输出约
`121.25 × 105.00 mm` 的底座，超过奖牌框实测内孔
`114.54187 × 100.00 mm`。旧发布 QA 只检查打印板边界，没有检查奖牌框装配边界，
因此错误成果未被阻止。

## 方法与事实

- 数据事实：奖牌框内轮廓不是理想正六边形，使用六个实测顶点作为唯一装配基准。
- V2 教训：直接沿实测框轮廓内缩虽然能安装，但实测框并非理想正六边形，导致外边与沙盘槽不平行，环宽视觉不一致。
- V3 制作方法：先由沙盘槽生成严格平行的正六边形外轮廓，再在奖牌框实测内孔中求最大可容纳偏移量。
- 奖牌框安全边界仍按 `0.30 mm`；V3 可见环宽恒定为 `4.594 mm`。
- V3 六条外边均为 `55.651 mm`，内外轮廓严格平行。
- V3 底座 3MF 实际网格包络：`110.6764 × 96.3908 mm`；未超过框内孔。
- 字体高度随有效环宽自动缩放到 `2.573 mm`，三处距内槽约 `1.01 mm`，中心误差不超过 `0.000002 mm`。
- V4 真机切片修正：V3 的 `2.573 mm` 中文虽有完整几何，但低于 0.4 mm 喷嘴的可靠笔画尺度；V4 将字高锁定为 `3.20 mm` 以上，本样本实际 `3.294 mm`，轮廓加强参数由 `0.12` 提高到 `0.20 mm`，两侧仍各保留约 `0.65 mm`。

## 流程修正

1. `run_generic_job_pipeline.py` 的底座阶段固定调用
   `rebuild_base_for_frame_glue_fit.py`；该脚本以沙盘槽和奖牌框共同求解平行等宽环。
2. `validate_generic_release.py` 新增双重门禁：
   - 检查底座报告的方法、公差和设计目标；
   - 直接读取 `02_*.3mf` 网格并检查实际 XY 尺寸不得超过奖牌框内孔。
3. 原 `final/` 与 V2 不覆盖；当前验证成果输出到 `final_parallel_ring_v3/`。

## 验证结论

- 5 个 3MF + 1 个 Blender：PASS。
- 四件同盘：4 个顶层对象、7 个材料子件，PASS。
- 所有 3MF：ZIP、非负 Z 与打印板范围检查 PASS。
- 奖牌框数字装配门禁：PASS；平行等宽环门禁：PASS。
- 中文可打印门禁：字高不得低于 `3.20 mm`，轮廓加强不得低于 `0.20 mm`。
- Blender 5.2 后台偶发 Metal 初始化崩溃；重试后成功，属于运行环境稳定性问题，
  不属于几何失败。后续应给后台 Blender 阶段增加有限次数自动重试。

## 假设与未决项

- `0.30 mm/边` 延续此前胶粘/橡胶圈装配决策；不同材料收缩仍需实物验证。
- 数字包络通过不等同于实物完全验收；下一步在 Bambu Studio 确认尺寸，并以奖牌框试装。
