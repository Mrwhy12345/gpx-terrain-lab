# 马拉松轨迹模型阶段总结

日期：2026-09-05
状态：流程已跑通两座城市；尚未宣称任意 GPX 全自动封板

## 1. 产品定位

GPX Terrain Lab 的轨迹模型分为两条产品线：

1. 徒步轨迹模型：重点表达地形高程、自然水系和路线与山体的关系。
2. 马拉松轨迹模型：重点表达城市道路、水体、建筑、赛事路线、标志建筑和奖牌式底座。

本阶段只固化马拉松轨迹模型。目标不是按测绘比例复制整座城市，而是在约 100 mm 的纪念沙盘中忠实保留 GPX 和主要空间关系，同时满足美观、触觉、强度、装配和多色 FDM 打印要求。

## 2. 已完成样本

### 悉尼马拉松

- 完成城市整体、红色轨迹、悉尼歌剧院和奖牌式底座的产品结构。
- 真机暴露并修复路网悬空、轨迹被道路挡槽、水体上装倒扣等问题。
- 建立水体最低、地面、道路、建筑依次升高的城市层次。
- 建立起点圆环＋方向三角、终点圆环＋靶心的触觉语义。
- 底座文字上框由薄框和点定位升级为加厚连续企口候选。

### 2026 梧州半程马拉松

- 验证全马流程可以复用于长宽比明显不同的半马 GPX。
- 使用 TrailPrint3D 保留西江、浔江、城市道路、建筑与路线的空间关系。
- 使用 Tripo 制作骑楼城牌坊，按真实位置、陆地约束及路线方向关系工程化安装。

## 3. 标准生产链

`GPX_AUDITED → TRAILPRINT_GENERATED → CREATIVE_CONFIRMED → MANUFACTURING_PASS → 3MF_PASS → BAMBU_SLICE_PASS → PHYSICAL_ACCEPTED → FINAL_SEALED`

### 输入与事实层

- 原始 GPX 永不覆盖，记录 SHA-256、点数、里程、时间、范围和异常跳点。
- 核实赛事全称、日期、官方距离和标志建筑。
- TrailPrint3D 负责 GPX、地图范围、道路、水体、建筑和空间关系，必须保留原生 Blend 与实际参数报告。
- GIS/OSM 用于审计和补充，不得无记录地替代 TrailPrint3D 坐标关系。

### 制造层

- Blender 用于装配预览、尺寸、地标工程化和打开即见的交付场景。
- Shapely、Trimesh、Manifold3D 用于二维清理、互斥分色、加固、布尔、开槽和水密实体。
- 城市整体采用“水体最低 → 地面 → 道路 → 建筑”；小建筑不逐栋拆装。
- 红色轨迹不得为构图修改；槽从最终轨迹同源派生，并验证完整 +Z 顶装路径。
- 标志建筑允许小幅艺术偏移，但必须保持真实区域、陆地、水体和路线方向关系。

### Bambu 与真机层

- 正式打印优先使用已验证母版派生的 Bambu 原生 3MF。
- 配色必须按真实 AMS 槽位和材料 HEX 再核对，不能只看材料名称都是 PLA。
- 精细文字版采用一个工程两个盘：盘 1 为 0.4 mm 的城市、轨迹、地标和厚底座；盘 2 为 0.2 mm 的双色连续文字上框。
- Bambu 喷嘴配置为项目级，必须切换喷嘴后逐盘单独切片和打印。
- “切片完成”不等于 PASS；浮空、重叠走线、盘外实体、无效 T 指令和料塔冲突均须解释或修复。

## 4. 当前输出标准

普通版本由四个装配模块组成：底座、城市整体、红色轨迹和标志建筑。精细文字版制造上为“4＋1”物理件，增加连续文字上框。

发布包至少包含：

- 标准兼容 3MF；
- Bambu 原生双盘 3MF；
- 最终 STL；
- 打开即见的装配 Blend；
- 含完整底座的斜侧视、顶视、底视与拆解图；
- GPX、地图、奖牌图案和地标来源记录；
- 几何、3MF、切片和真机 QA；
- README、打印装配说明和 SHA-256 清单；
- 不可覆盖的 FINAL/SEALED 封板包。

## 5. 已固化的经验

- Blender 看起来对齐不等于真实可安装。
- BVH 表面零碰撞不等于实体无占用。
- 开槽后进行全局体素重建可能把槽重新填回。
- 3MF 能打开不等于耗材、对象层级和盘位正确。
- 仅写 plate 元数据会出现空盘或盘外；必须同步根模型变换、实例归属和全局坐标，并以 GUI 为准。
- 道路和建筑必须有连续承托；单纯增加高度会放大悬空和拉丝。
- 底座图案必须采用“可追溯原图 → 元素选择 → PNG 锁稿 → 实体嵌色”，未见原图不得臆造。
- 任何打印零件发生变化，完整套装统一升版；候选版不得换名冒充封板版。
