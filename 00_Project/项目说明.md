# 把一次徒步变成一座山

## 项目目标

将真实徒步GPX轨迹转换为可多色3D打印的地形模型。

## 更新后的产品目标

项目已从单个学习作品升级为可对外使用的“GPX 徒步沙盘生成系统”：

- 输入：一个 GPX 轨迹文件；
- 输出：沙盘、底座、轨迹、水体四个保持同一装配坐标的多色 3MF；
- 中间链路：DEM/OSM → QGIS 空间处理 → 高德在线人工核验 → Blender
  可制造几何 → 3MF 自动 QA；
- 系统应在不修改代码的情况下处理新的 GPX。

完整范围、MVP 和阶段路线见：`对外系统目标.md`。

项目团队分工、成员成长轨迹和任务交接见：`团队档案/README.md`。

## 当前作品目标

以“2025-02-23 从化星溪线（星溪竹林）”为首个完整案例：

1. 保留真实徒步路线和地形；
2. 从可靠GIS数据源补充、核验和整理真实水系；
3. 将地形、徒步路线和水体制作为独立对象；
4. 导出多部件3MF并在Bambu Studio中完成多色切片；
5. 使用H2C完成实体打印；
6. 记录数据验证、建模、切片、打印、失败和修正过程。

星溪线 S02/V010 作为系统的第一个金标准案例和回归基线。

## 工作区约束

现有目录结构作为项目固定骨架：

- 不移动已有目录；
- 不重命名已有目录和实验；
- 不删除或覆盖已有原始数据及实验结果；
- 新内容只在现有分类下扩展；
- 中间数据放入对应实验的 `data` 或 `process`；
- 可交付模型放入对应实验的 `result`；
- 截图和学习证据放入对应实验的 `screenshots` 或 `review`。

## 核心流程

GPX
→ GIS数据源验证
→ QGIS水系核验与整理
→ TrailPrint3D地形
→ Blender多部件建模
→ 3MF
→ Bambu Studio
→ H2C打印

## 学习目标

1. 理解GPX、DEM和3D地形关系
2. 掌握TrailPrint3D工作流
3. 建立多色打印参数经验
4. 形成可复用设计规范

## 学习方式

每次实验：
目标
→ 实操
→ 录屏
→ AI复盘
→ 参数总结
→ 下一轮实验

AI协作时必须区分：

- 已观察事实；
- 原因假设；
- 下一步建议；
- 已验证、可进入知识库的结论。
