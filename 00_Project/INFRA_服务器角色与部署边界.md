| 节点 | 定位 | 主要职责 | 当前状态 |
|---|---|---|---|
| Neo MacBook | 开发服务器 | 便携开发、代码修改、调试、提交 GitHub | 使用中 |

| 上海服务器 | 国内 Web 生产服务器 | 国内客户访问的前端、公共 API、任务入口与状态服务 | SSH 通道已建立，待部署 |

## 2. 固定职责边界

### Neo MacBook

- 是开发环境，不承担正式客户流量和生产任务存储。
- 可以连接 GitHub、测试服务器和生产服务器完成受控发布。
- 本地代码是工作副本；GitHub `main` 是代码发布基线。

### Mac mini

- 是前端 Web 的测试服务器，用于上线前验收。
- 是 TrailPrint3D、Blender、3MF 和 Bambu QA 的生产计算后端。
- 位于家庭网络，不直接向公网暴露 Blender、文件系统或内部计算接口。
- 采用主动出站方式，从国内或海外生产服务器领取任务并上传结果。

### 上海服务器

- 是国内 Web 的生产入口。
- 承担 HTTPS、前端静态资源、公共 API、匿名任务身份、排队状态和下载授权。
- 不运行 Blender 等重计算任务。
- 已验证 Neo MacBook 可通过专用非 root 通道登录：
  - SSH Host 别名：`gpx-shanghai-web`
  - 用户：`webapp`
  - 主机名：`VM-0-16-ubuntu`
  - 用户目录：`/home/webapp`
  - 验证结果：`whoami / hostname / pwd` 均符合预期
- 服务器 IP、私钥和认证信息不写入项目仓库。

### 首尔服务器

- 是海外 Web 的生产入口，职责与上海服务器对称。
- 国内、海外节点应使用同一版本和同一 API 契约，配置、域名与存储区域独立。
- 不运行 Blender 等重计算任务。

### 群晖 NAS

- 未来作为持久化存储和备份节点，不直接作为公网 Web 入口。
- 启用前必须明确目录、权限、加密、备份、保留期和故障恢复策略。
- 未启用期间，不能让系统设计默认为群晖已经可用。

## 3. 目标数据流

```text
开发与发布
Neo MacBook → GitHub → 上海/首尔 Web 生产服务器

客户任务
国内客户 → 上海服务器 ┐
                         ├→ 任务队列 → Mac mini 计算 Worker
海外客户 → 首尔服务器 ┘                    │
                                           └→ 预览与 5+1 成果回传

未来持久化
上海/首尔任务与成果 → 群晖 NAS（启用后）
```

## 4. 当前部署原则

1. 开发、测试、Web 生产、计算生产和持久化存储必须区分。
2. Mac mini 同时承担“Web 测试”和“生产计算后端”，但不承担公网 Web 生产入口。
3. 上海与首尔只承担 Web 生产职责，不把 Blender 暴露公网。
4. 两个 Web 生产节点共用代码版本和任务契约，不共用未经隔离的客户会话。
5. 群晖未启用前，任务数据库与对象存储必须有明确的临时落点和备份策略。
6. 所有 Agent 在部署、排障和文档中必须使用本文节点名称，不得把 Neo、Mac mini 或上海服务器混称为“本地服务器”。

## 5. 部署账号与连接通道

Mac mini、上海服务器和首尔服务器上的每一类服务，都使用专用非 root 账号和独立连接通道进行部署。

### 强制规则

1. 禁止使用 `root` 账号直接部署或长期运行应用。
2. 禁止不同服务共用同一个部署账号、SSH 私钥或访问凭证。
3. 每个部署账号只拥有对应代码目录、运行目录、日志目录和服务进程所需的最小权限。
4. 需要系统级变更时，使用受限 `sudo` 命令白名单，不授予完整 root shell。
5. 开发、测试、国内生产、海外生产的连接配置和密钥相互独立。
6. 私钥、令牌和生产配置不得提交到 GitHub；仓库只保存配置模板和变量名称。
7. 每次部署必须记录服务器、账号、代码版本、提交哈希、部署时间、执行结果和回滚点。
8. Agent 在连接前必须先确认“目标服务器 + 服务名称 + 账号 + 权限范围”，不得根据 IP 猜测环境。

### 建议命名

建议按“服务 + 环境”命名账号，最终名称以实际创建结果为准：

| 节点 | 账号示例 | 用途 |
|---|---|---|
| Mac mini | `gpx_web_test` | Web 测试部署与运行 |
| Mac mini | `gpx_compute_worker` | TrailPrint3D、Blender、3MF、Bambu QA Worker |
| 上海服务器 | `gpx_web_cn` | 国内 Web 生产部署与运行 |
| 首尔服务器 | `gpx_web_global` | 海外 Web 生产部署与运行 |

群晖启用后，应另建专用存储服务账号；生产服务器和 Mac mini 不共用群晖管理员账号。

### 连接资料登记要求

项目文档只登记以下非敏感信息：

- SSH Host 别名；
- 节点和服务用途；
- 非 root 用户名；
- 允许访问的目录与服务；
- 公钥指纹；
- 运维责任人和启停方法。

服务器 IP、私钥路径、令牌和密码保存在本机受控 SSH 配置或密码管理工具中，不写入公开仓库。
