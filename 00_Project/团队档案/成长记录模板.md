# 成长记录模板

将以下内容追加到对应成员的 `成长档案.md`。

```markdown
## YYYY-MM-DD｜实验或版本｜成长主题

### 本次任务

- 

### 使用模型

- 默认：🌍 Terra / 🌙 Luna / ☀️ Sol
- 是否切换：
- 切换原因：

### 产出证据

- `项目内路径`

### 新掌握

- 

### 失败与修正

- 观察事实：
- 原因判断：
- 修正方法：
- 如何防止再次发生：

### 能力变化

- 能力项：等级 X → Y
- 升级依据：

### 下一步

- 
```

要求：

- 没有证据路径，不升级能力等级；
- 只有推断时必须标记为假设；
- 失败记录不能只写错误信息，要写诊断方法；
- 同类问题第二次出现时，应由 🐾 丁满负责工具化。
