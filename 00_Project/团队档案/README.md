## 公共文件

- `团队成长看板.md`：当前能力、阶段成绩和短板；
- `任务交接记录.md`：跨角色交付和验收；
- `成长记录模板.md`：以后每个阶段统一追加的格式。

## 文件原则

1. 不复制项目成果，只记录成果的原始路径；
2. 不移动 S01/S02、工具和封版文件；
3. 每项成长必须指向证据，不能只写“学会了”；
4. 同时记录成功、失败、判断变化和未完成项；
5. 专项角色完成交付后，必须进入任务交接记录；
6. 阶段封版后，五位成员各追加一条成长记录；
7. S02 以前的成果按职责回溯映射，不表示当时确实运行了五个独立 Agent。

## 能力等级

| 等级 | 含义 |
|---:|---|
| 1 | 了解概念，需要完整指导 |
| 2 | 能在模板下完成任务 |
| 3 | 能独立完成常规任务 |
| 4 | 能诊断异常并改进流程 |
| 5 | 已有可复用方法、验证证据和交接规范 |

## 更新触发条件

- 新实验开始；
- 发生一次有价值的失败；
- 新增可复用脚本；
- 通过一次真机验收；
- 完成一次版本封版；
- 新 GPX 无需改代码即可完成生成；
- 某角色需要从 Luna/Terra 升级到 Sol。
