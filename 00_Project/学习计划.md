# 学习计划

## 第一阶段：环境搭建

目标：
完成MacBook Neo环境配置。

软件：
- Blender
- TrailPrint3D
- Bambu Studio


## 第二阶段：首次生成

目标：
完成第一次GPX到3D地形。


## 第三阶段：打印优化

研究：
- 地形分辨率
- 垂直比例
- 路线宽度
- 多色结构


## 第四阶段：作品化

目标：
制作具有纪念价值的徒步模型。


## 第五阶段：系统化

目标：
把 S02 已验证的 GPX、QGIS、高德核验、Blender 和 3MF 工作链参数化。

交付：
- 统一 `job.json`；
- 单命令生成四个 3MF；
- 阶段失败恢复；
- 自动 QA 报告。


## 第六阶段：对外产品

目标：
建立本地优先的 Web 工作台，实现 GPX 上传、候选核验、模型预览和下载。

验收：
- 至少 5 条不同 GPX；
- 至少 3 次实体打印；
- 新路线无需修改代码；
- 明确隐私、许可和数据归属。
