## 四个最重要入口

### 1. 🔴 要打印

进入：

`06_Experiment/SYS01_TerrainPackagingPrototype/releases/V008_一体水系跨轨/用于打印_3MF/`

这里只使用编号 `01–05` 的 3MF。不要从 `data/`、`result/` 或“故障备份”打印。

### 2. 🔴 要看 Blender 效果

进入：

`06_Experiment/SYS01_TerrainPackagingPrototype/releases/V008_一体水系跨轨/设计预览_Blender/`

### 3. 🔴 要增加一条新徒步路线

原始 GPX 放入：

`02_GPX/Original/`

原文件只读；处理结果写入 `02_GPX/Processed/` 或新的实验目录。

### 4. 🔴 要继续开发或交给新 Agent

先阅读：

`00_Project/后续Agent交接总览_2026-07-29.md`

自动化代码位于：

`07_Knowledge/tools/`

## 一句话记忆

**00 看方向 → 02 放 GPX → 06 做模型并从 releases 拿成品 → 07 存自动化能力。**

## 文件安全规则

1. `02_GPX/Original/` 永不覆盖。
2. `final/` 是 V007 历史基准，不再作为最新版本入口。
3. 最新成果只从 `releases/版本号/` 获取。
4. `data/`、`result/` 是中间产物，不直接交付。
5. `故障备份_*` 只用于追溯，不允许进入打印流程。
