# E104：三方对比

状态：⬜ 待开始

## 前置条件

E101、E102、E103 全部完成。

## 对比指标

### 模型指标

| 指标 | 合格标准 |
|------|----------|
| 输出对象名称 | 一致 |
| 对象数量 | 一致 |
| Bounding Box XYZ | 差异 ≤ 0.01 mm |
| 顶点数 | 原则上相同 |
| 面数 | 原则上相同 |
| 体积 | 相对差异 ≤ 0.1% |
| Z 最小值/最大值 | 一致 |
| 非流形边 | 无新增问题 |
| 地图与轨迹变换 | 一致 |
| 文件是否可导入 | 全部通过 |

### 切片指标

统一用 H2C、0.4 mm 喷嘴和同一预设。

| 指标 | 说明 |
|------|------|
| 切片是否成功 | 全部通过 |
| 打印时间 | 记录对比 |
| 总耗材 | 记录对比 |
| 各颜色耗材 | 记录对比 |
| 层数 | 记录对比 |
| 首层预览 | 视觉一致 |
| 轨迹是否连续 | 无断裂 |
| 空中打印/重叠/缺失 | 无 |

## 等价性结论模板

每个指标填写三组数据（E101/E102/E103），给出最终分级：

- **PASS**：打印等价
- **PASS WITH DIFFERENCES**：存在差异但等价
- **FAIL**：不可接受差异
